## Workspaces (<Meh /> Meh + Number)

| Shortcut    | Action                  |
|-------------|-------------------------|
| <Meh key="1-9" /> | Switch to workspace    |
| <Meh key="Z" /> | Workspace Z (monitor)  |
| `Alt + Tab`  | Previous workspace     |

## Manage mode (<Meh key="W" />, then key)

| Key              | Action                       |
|------------------|------------------------------|
| `H/J/K/L`       | Move window                  |
| `Shift + H/J/K/L` | Join with direction        |
| `1-9, Z`         | Send window to workspace    |
| `T`              | Toggle tiles                |
| `S`              | Toggle accordion            |
| `F`              | Fullscreen                  |
| `Shift + F`      | Toggle floating/tiling      |
| `E`              | Balance sizes               |
| `-` / `=`        | Shrink / grow               |
| `Tab`            | Move workspace to monitor   |
| `R`              | Reset layout                |
| `Shift + R`      | Reload config               |
| `Backspace`      | Close all but current       |
| `Esc`            | Exit manage mode            |
