Hold **Caps Lock** and press a key to type programming symbols that are awkward to reach on the ES-ISO layout.

<Keyboard rows={[
  [
    { label: "Y", symbol: "@" },
    { label: "U", symbol: "{" },
    { label: "I", symbol: "}" },
    { label: "O", symbol: "[" },
    { label: "P", symbol: "]" },
  ],
  [
    { label: "N", symbol: "->" },
    { label: "M", symbol: "=>" },
    { label: ",", symbol: "`" },
    { label: ".", symbol: "#" },
    { label: "-", symbol: "|" },
  ],
]} />

`ñ` → `~` is also available but not shown above.

## Brackets

Left opens, right closes. Top row, left to right.

| Shortcut  | Output |
|-----------|--------|
| <Meh key="U" /> | `{`    |
| <Meh key="I" /> | `}`    |
| <Meh key="O" /> | `[`    |
| <Meh key="P" /> | `]`    |

## Arrows

| Shortcut  | Output |
|-----------|--------|
| <Meh key="N" /> | `->`   |
| <Meh key="M" /> | `=>`   |

## Other symbols

| Shortcut  | Output  |
|-----------|---------|
| <Meh key="Y" /> | `@`     |
| <Meh key="," /> | `` ` `` |
| <Meh key="." /> | `#`     |
| <Meh key="-" /> | `\|`    |
| <Meh key="ñ" /> | `~`     |
