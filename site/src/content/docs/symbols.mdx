## Brackets

Stacked vertically, growing top to bottom. Left opens, right closes.

| Shortcut | Output |
|----------|--------|
| `Meh + U` | `(` |
| `Meh + I` | `)` |
| `Meh + J` | `[` |
| `Meh + K` | `]` |
| `Meh + M` | `{` |
| `Meh + ,` | `}` |

## Arrows

| Shortcut | Output |
|----------|--------|
| `Meh + Y` | `->` |
| `Meh + O` | `=>` |

## Other symbols

| Shortcut | Output |
|----------|--------|
| `Meh + H` | `` ` `` |
| `Meh + L` | `\|` |
| `Meh + ñ` | `~` |
| `Meh + N` | `@` |
| `Meh + .` | `#` |
