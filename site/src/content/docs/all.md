|-----------|---------|
| `Meh + U` | `{`     |
| `Meh + I` | `}`     |
| `Meh + O` | `[`     |
| `Meh + P` | `]`     |
| `Meh + N` | `->`    |
| `Meh + M` | `=>`    |
| `Meh + Y` | `@`     |
| `Meh + ,` | `` ` `` |
| `Meh + .` | `#`     |
| `Meh + -` | `\|`    |
| `Meh + ñ` | `~`     |

## Cursor (Hyper + Key)

| Shortcut     | Action |
|--------------|--------|
| `Hyper + H`  | Left   |
| `Hyper + J`  | Down   |
| `Hyper + K`  | Up     |
| `Hyper + L`  | Right  |

## Window focus (Meh + Key)

| Shortcut  | Action      |
|-----------|-------------|
| `Meh + H` | Focus left  |
| `Meh + J` | Focus down  |
| `Meh + K` | Focus up    |
| `Meh + L` | Focus right |

## Workspaces (Meh + Number)

| Shortcut    | Action                  |
|-------------|-------------------------|
| `Meh + 1-9` | Switch to workspace    |
| `Meh + Z`   | Workspace Z (monitor)  |
| `Alt + Tab`  | Previous workspace     |

## Manage mode (Meh + W, then key)

| Key              | Action                       |
|------------------|------------------------------|
| `H/J/K/L`       | Move window                  |
| `Shift + H/J/K/L` | Join with direction        |
| `1-9, Z`         | Send window to workspace    |
| `T`              | Toggle tiles                |
| `S`              | Toggle accordion            |
| `F`              | Fullscreen                  |
| `Shift + F`      | Toggle floating/tiling      |
| `E`              | Balance sizes               |
| `-` / `=`        | Shrink / grow               |
| `Tab`            | Move workspace to monitor   |
| `R`              | Reset layout                |
| `Shift + R`      | Reload config               |
| `Backspace`      | Close all but current       |
| `Esc`            | Exit manage mode            |
