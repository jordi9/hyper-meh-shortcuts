<Meh key="Letter" /> opens or focuses an app instantly via Raycast. No launcher UI, no searching.

## App hotkeys

| Shortcut  | App             |
|-----------|-----------------|
| <Meh key="A" /> | Ghostty         |
| <Meh key="S" /> | IntelliJ IDEA   |
| <Meh key="D" /> | DaVinci Resolve |
| <Meh key="F" /> | Ferdium         |
| <Meh key="G" /> | Google Gemini   |
| <Meh key="X" /> | Roon            |
| <Meh key="V" /> | Vivaldi         |
| <Meh key="R" /> | Notion          |
| <Meh key="T" /> | TickTick        |

## Other Raycast hotkeys

| Shortcut | Action |
|----------|--------|
| `Option + Cmd + 8` | Clipboard History |

These are configured in Raycast preferences under Hotkeys. To change them, open Raycast Settings and assign a new hotkey to any app or command.
