---
title: Applications
description: Instant app switching via Raycast hotkeys on the Meh layer.
---

**Meh + Number** opens or focuses an app instantly via Raycast. No launcher UI, no searching.

## App hotkeys

| Shortcut | App |
|----------|-----|
| `Meh + 0` | Ghostty |
| `Meh + 1` | IntelliJ IDEA |
| `Meh + 3` | Ferdium |
| `Meh + 5` | Google Gemini |
| `Meh + 7` | Roon |
| `Meh + 9` | Vivaldi |
| `Hyper + N` | Notion |

## Other Raycast hotkeys

| Shortcut | Action |
|----------|--------|
| `Option + Cmd + 8` | Clipboard History |
| `Shift + Cmd + E` | TickTick |

These are configured in Raycast preferences under Hotkeys. To change them, open Raycast Settings and assign a new hotkey to any app or command.
