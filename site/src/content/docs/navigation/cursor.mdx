import Hyper from '../../../../src/components/Hyper.astro';

Hold **Caps Lock + Cmd** and press HJKL for arrow keys without leaving the home row.

| Shortcut | Action |
|----------|--------|
| <Hyper key="H" /> | Left |
| <Hyper key="J" /> | Down |
| <Hyper key="K" /> | Up |
| <Hyper key="L" /> | Right |

Standard Vim layout. Works everywhere in macOS — text editors, browsers, Finder, dialogs. Combine with `Shift` for text selection.
